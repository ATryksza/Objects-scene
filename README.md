# 🧊 3D Objects Scene

A C++ 3D graphics application for loading and rendering 3D objects with configurable camera, shading, fog, and lighting settings.

The project includes OBJ model parsing, triangle rasterization, and basic 3D scene rendering.

## 🎥 Demo

## ✨ Features

- loading 3D objects,
- adjustable camera position,
- configurable field of view (FOV),
- three selectable camera views,
- multiple shading modes:
  - Constant,
  - Gouraud,
  - Phong,
- customizable object color,
- optional fog effect,
- optional lighting.

## 🛠️ Technologies

- C++
- 3D graphics
- OBJ

## 🎯 Project Goal

The project was created to explore fundamental 3D graphics techniques, including object loading, camera manipulation, shading, lighting, and rendering.
